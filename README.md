# AI Skills RU

**Библиотека профессиональных навыков для ИИ-агентов, адаптированных для русскоязычной аудитории.**

## О проекте

AI Skills RU — библиотека структурированных профессиональных методологий, инструкций, стандартов и рабочих подходов, оформленных в открытом формате [Agent Skills](https://agentskills.io/specification).

Обычный промпт решает одну разовую задачу и зависит от точности формулировки. Skill — это воспроизводимая профессиональная методология: агент подключает её целиком и работает по проверенному стандарту, а не по пересказу задачи. Это делает результат предсказуемым: один и тот же Skill в разных задачах даёт работу одинакового качества и структуры.

Библиотека предназначена для людей и организаций, которые используют ИИ-агентов для решения реальных профессиональных, деловых, аналитических и управленческих задач **на русском языке**. Массовые инструменты и шаблоны спроектированы под англоязычную деловую среду: механический перенос их конструкций на русский язык ухудшает результат — возникают кальки, неуместные форматы документов, чужие правовые допущения. Этот проект изначально проектируется под русскоязычную профессиональную среду: язык, форматы документов, деловой контекст и правовые особенности.

Практическая польза: пользователь получает готовые профессиональные стандарты работы агента — без необходимости самостоятельно составлять и отлаживать длинные инструкции — а организация получает единый подход к типовым задачам (документы, анализ, коммуникации) независимо от того, кто из сотрудников ставит задачу.

## Принципы

1. Практическая применимость важнее количества Skills.
2. Каждый Skill решает конкретную профессиональную задачу.
3. Инструкции понятны, проверяемы и воспроизводимы.
4. Нельзя выдавать предположения за факты.
5. Нельзя имитировать экспертность за счёт сложного языка и объёма.
6. Международные методологии адаптируются, а не переводятся механически.
7. Каждый Skill проходит практическое тестирование.
8. Совместимость с платформами подтверждается отдельно.
9. Избегаем избыточной сложности и ненужной инфраструктуры.
10. Каждый Skill имеет понятную область применения и ограничения.

## Использование

Каждый Skill — директория внутри `skills/`:

```text
skills/<skill-name>/
├── SKILL.md          # обязательный файл: метаданные + инструкции
└── references/       # дополнительные материалы, загружаемые по мере необходимости
```

`SKILL.md` содержит YAML frontmatter (`name`, `description`) и инструкции агента; подробные материалы вынесены в `references/` и подключаются по требованию (progressive disclosure).

Skills используются в средах, поддерживающих формат Agent Skills (Claude Code, OpenCode и другие): директория Skill копируется в каталог Skills пользователя или проекта. Совместимость конкретной платформы и каталоги установки необходимо проверять по документации этой платформы — универсальная совместимость не заявляется.

## Разработка новых Skills

Требования к новому Skill:

- конкретная задача — один Skill решает одну понятную профессиональную задачу;
- понятная область применения и явные ограничения;
- полноценные инструкции в `SKILL.md`, при необходимости — дополнительные материалы в `references/`;
- практическое тестирование на реальных сценариях до публикации;
- проверка ограничений и совместимости платформ — отдельно и без неоснованных заявлений.

## Стандарт

Проект использует открытый формат [Agent Skills](https://agentskills.io/specification). Авторы и владельцы стандарта — сторонние разработчики спецификации; этот проект является пользователем формата, а не его автором.

## Язык и контекст

Основной язык пользовательских инструкций и материалов библиотеки — русский. Технические идентификаторы, имена файлов, поля формата и другие элементы, требуемые спецификацией Agent Skills, могут оставаться на английском языке.
