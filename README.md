# ai-skills

Библиотека AI Skills для использования в разных AI-инструментах: Claude Code, OpenCode, ZCode, Codex и других совместимых средах.

## Назначение

Репозиторий — основное хранилище и источник актуальной версии библиотеки навыков. Локальная рабочая копия используется для разработки и тестирования; GitHub — источник истины.

## Стандарт

Навыки организованы по открытому стандарту [Agent Skills](https://agentskills.io/specification) (полная спецификация: https://agentskills.io/specification):

- каждый Skill — директория с обязательным файлом `SKILL.md` (YAML frontmatter + Markdown-инструкции);
- обязательные поля frontmatter: `name` (до 64 символов, строчные буквы, цифры и дефисы, совпадает с именем директории) и `description` (до 1024 символов — что делает Skill и когда его применять);
- необязательные поля: `license`, `compatibility`, `metadata`, `allowed-tools`;
- дополнительные материалы располагаются в `scripts/`, `references/`, `assets/` и загружаются агентом по мере необходимости (progressive disclosure);
- рекомендуется держать `SKILL.md` до 500 строк, вынося детали в отдельные файлы.

Валидация навыков: `skills-ref validate ./my-skill` (см. [agentskills/agentskills](https://github.com/agentskills/agentskills)).

## Принцип расширения библиотеки

- Новый Skill = новая директория в `skills/<skill-name>/` с файлом `SKILL.md`.
- Навык добавляется только после утверждения содержания; в репозиторий не помещаются заготовки без содержания.
- Материалы внутри навыка разбиваются по progressive disclosure: инструкции — в `SKILL.md`, детали — в `references/`, исполняемый код — в `scripts/`, шаблоны — в `assets/`.
- Пользовательские материалы (README, инструкции, справочные материалы, шаблоны, примеры) ведутся на русском языке; технические идентификаторы и названия Skills могут оставаться на английском.

## Совместимость сред

| Среда | Формат Agent Skills | Способ подключения | Подтверждено официальной документацией |
|---|---|---|---|
| Claude Code | Да | Копирование директории Skill в `~/.claude/skills/` (личный) или `.claude/skills/` (проект); плагины и marketplace | Да (docs Claude Code) |
| OpenCode | Да | `~/.config/opencode/skills/` или `.opencode/skills/`; совместимость с `~/.claude/skills`, `.agents/skills`; пользовательские источники в `opencode.json` | Да (opencode.ai/docs/skills) |
| ZCode | Да | Каталоги пользовательских и проектных Skills (как у skills данного окружения, например `~/.zcode/skills/` и `.agents/skills/`) | Частично — подтверждено работой данного окружения, детали каталогов требуют сверки с документацией ZCode |
| Codex | Нет нативной поддержки формата | Возможна адаптация: подключение `SKILL.md` как инструкции в `AGENTS.md` / конфигурации | Нет — требует дополнительной проверки |
| ChatGPT | Нет нативной поддержки формата | Возможна адаптация через GPTs / проекты с загрузкой содержимого Skill как файла знаний | Нет — требует дополнительной проверки |
